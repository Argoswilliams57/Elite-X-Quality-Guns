# Elite X Quality Guns

**A Minecraft weapon mod focused on expanding the gunplay experience.**

Elite X Quality Guns is an open-source Minecraft mod project developed by Argos Studios.

## Supported Versions

- Minecraft 26.3
- Multiloader project supporting the platforms configured in this branch.

## Features

- Custom firearms and weapon content.
- Animated weapon models.
- Content designed to expand Minecraft's gunplay experience.
- Multiloader architecture for supported mod loaders.

## Installation

1. Install the appropriate Minecraft version and mod loader.
2. Download the compatible Elite X Quality Guns release.
3. Install the required dependencies.
4. Place the mod JAR in your Minecraft `mods` folder.
5. Launch the game.

Check the release notes for version-specific requirements.

## Building from Source

This project uses Gradle.

Clone the repository and select the appropriate branch:

- `1.21.1-elitex` — Minecraft 1.21.1 project.
- `26.3-elitex` — Minecraft 26.3 project.

Use the Gradle wrapper included with the project to build the configured modules.
